# Adidas Sales Dashboard

A responsive static website exploring an Adidas US sales sample dataset for 2020–2021. The dashboard includes region and product filters, sales and profit KPIs, regional profit mix, product sales, and yearly trends.

## Run locally

Open `index.html` in a modern browser. No build step or installation is required.

## Dataset and interpretation

Source dataset: [Adidas US Sales Dataset on Kaggle](https://www.kaggle.com/datasets/heemalichaudhari/adidas-sales-dataset).

The provided workbook's `Total Sales` and `Operating Profit` fields are retained. Data quality note: 3,886 of 9,648 source rows report sales exactly 10 times `Price per Unit × Units Sold`. The number of source rows also differs substantially between 2020 and 2021, so interpret year-over-year changes cautiously. This is a public sample dataset and is not verified company-reported Adidas data.
